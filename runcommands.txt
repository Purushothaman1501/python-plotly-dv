# Student Analytics Dashboard - Run Commands

## Backend (Flask API)
# 1. Navigate to the student_dashboard directory
cd /home/purushotaman/Desktop/learning/python-plotly-dv/python-plotly-dv/student_dashboard

# 2. Activate the virtual environment
source venv/bin/activate

# 3. Run the Flask backend
python backend/main.py

# The API will be available at http://127.0.0.1:5000
